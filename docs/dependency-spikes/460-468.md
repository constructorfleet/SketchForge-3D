# Dependency upgrade spikes: #460–#468

Date: 2026-10-24. Combined review branch: `deps/spikes-460-468`.

The PR retains only the Electron 45 and js-yaml 5 upgrades in the manifests. The other requested major upgrades are left unchanged because their spike gates exposed unresolved compatibility issues or they could not be validated independently. The exact outcomes below are from the combined spike attempt; Electron's packaging result was already recorded on #461.

| Issue | Upgrade | Result |
| --- | --- | --- |
| #460 | Next 15.5.28 → 16.4.3 | Blocked: `npm run build` failed because Next 16 selected Turbopack while the existing config uses webpack. The upgrade is not included. |
| #461 | Electron 43.8.1 → 45.0.0 | Included. The existing issue comment records a successful macOS arm64 directory package; Windows, Linux, macOS x64, signed installers, and installed-app update behavior remain unverified. |
| #462 | Vitest 4.1.12 → 5.0.5 | Not independently validated; the combined typecheck failed before the Vitest suites ran. The upgrade is not included. |
| #463 | TypeScript 5.9.3 → 7.0.2 | The combined root typecheck failed. The upgrade is not included. |
| #464 | occt-wasm 3.6.1 → 5.8.0 | The combined root typecheck reported incompatible `OcctKernel` and branded `ShapeHandle` identities. STEP round-trip and performance gates were not run. The upgrade is not included. |
| #465 | brepjs 18.118 → 20.10.3 | Engine build passed, but the combined root typecheck failed; STEP round-trip and performance gates were not run. The upgrade is not included. |
| #466 | Three.js 0.184 → 0.186.1 and @types/three 0.184 → 0.186 | The combined root typecheck reported incompatible duplicate `BufferGeometry` and `Quaternion` types. Browser/editor coverage was not run. The upgrade is not included. |
| #467 | Mermaid 11 → 12.2.0 | Blocked: latest `vitepress-plugin-mermaid` is 2.0.17 and declares peer support for Mermaid 10 or 11. Mermaid 12 is not included. |
| #468 | js-yaml 4 → 5.5.0 | Included. Version 5 has no ESM default export; the release asset script and docs tests now use namespace imports. CI caught the compatibility issue, and the focused local YAML workflow/release tests pass. |

## Verification on the final manifest

- `npx --yes npm@10.9.9 install --package-lock-only` — passed. The lockfile was generated with the npm major used in CI, from a clean install state.
- `npx --yes npm@10.9.9 ci` — passed.
- `npm ls occt-wasm three @types/three --all` — passed; root and engine resolve the same versions, with no duplicate type identities.
- `npm run typecheck` — passed.
- `npm run test` — 193 suites passed; one docs suite failed because the local Python runtime lacks `typing.is_typeddict` (CI config uses Python 3.12).
- Focused docs tests for YAML workflow parsing and desktop/release consumers — 100 passed; the package-reference test in that selection hit the same local Python limitation.
- `npm run build` — passed with Next 15.5.28.

Only Electron 45 and js-yaml 5 are included in the final dependency diff. The remaining issue upgrades need isolated follow-up branches with their named gates before promotion.
