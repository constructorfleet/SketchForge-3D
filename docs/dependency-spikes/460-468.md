# Dependency upgrade spikes: #460–#468

Date: 2026-10-24. Branch: `deps/spikes-460-468`.

This combined spike updates the root manifest and lockfile for the compatible requested versions and aligns the engine package's direct dependency ranges for Three.js, brepjs, occt-wasm, and TypeScript. Mermaid remains on 11 because the current VitePress plugin has no published release that declares Mermaid 12 support. The spike records feasibility only; it is not a promotion of these versions for release.

| Issue | Upgrade | Result |
| --- | --- | --- |
| #460 | Next 15.5.28 → 16.4.3 | Blocked: `npm run build` fails because Next 16 selects Turbopack while `apps/web/next.config.ts` contains a webpack configuration and no Turbopack configuration. |
| #461 | Electron 43.8.1 → 45.0.0 | The existing issue comment records a successful macOS arm64 directory package and its platform/signing limitations. The manifest and lockfile are included here; the recorded package result was not repeated in this combined run. |
| #462 | Vitest 4.1.12 → 5.0.5 | Not validated: the combined typecheck failed before unit, e2e, integration, browser, or performance suites could be run. |
| #463 | TypeScript 5.9.3 → 7.0.2 | Blocked: root typecheck fails with incompatibilities across packages, including duplicated package type identities. |
| #464 | occt-wasm 3.6.1 → 5.8.0 | Blocked: root typecheck reports incompatible `OcctKernel` and branded `ShapeHandle` types resolved from root and engine installations. STEP round-trip and performance gates were not run. |
| #465 | brepjs 18.118 → 20.10.3 | Not independently validated: the combined root typecheck fails; engine build/typecheck passed, but STEP round-trip and performance gates were not run. |
| #466 | Three.js 0.184 → 0.186.1 and @types/three 0.184 → 0.186 | Blocked: root typecheck reports incompatible duplicate `BufferGeometry` and `Quaternion` types from root and engine installations. Browser/editor rendering and transform coverage was not run. |
| #467 | Mermaid 11 → 12.2.0 | Blocked: `vitepress-plugin-mermaid@2.0.17` declares peer support for Mermaid 10 or 11, and 2.0.17 is the latest published release. Mermaid 12 is therefore not included. Docs checks and site build were not run. |
| #468 | js-yaml 4 → 5.5.0 | Version resolved and was included in the combined install. YAML consumer, docs, and release workflow tests were not run after the root typecheck failed. |

## Commands and results

- `npm install next@^16.4.3 electron@^45.0.0 vitest@^5.0.5 @vitest/mocker@^5.0.5 typescript@^7.0.2 occt-wasm@^5.8.0 brepjs@^20.10.3 three@^0.186.1 @types/three@^0.186.0 mermaid@^12.2.0 js-yaml@^5.5.0` — reproduced `ERESOLVE` for Mermaid 12 and the current VitePress plugin.
- Mermaid was left at `^11.17.2`; `npm view vitepress-plugin-mermaid versions --json` confirmed 2.0.17 is the latest published version, and its peer range is `mermaid: 10 || 11`.
- `npx --yes npm@10.9.9 install --package-lock-only` — passed and regenerated the lockfile using the npm major used in CI.
- `npx --yes npm@10.9.9 ci` — passed (655 packages added). The prior npm 11 generated lockfile omitted peer/optional entries required by npm 10, which caused the CI `npm ci` failures.
- `npm run typecheck` — failed with broad type errors, including duplicate Three.js and occt-wasm type identities across the root and engine package.
- `npm run engine:typecheck` — not reached as a separate command; `npm run typecheck` runs `engine:build` first, which passed.
- `npm run client:typecheck` — not reached because the preceding root typecheck failed.
- `npm run test` — not reached because the preceding root typecheck failed.
- `npm run build` — failed in Next 16 when Turbopack encountered the existing webpack configuration.

This spike intentionally leaves the remaining dependency incompatibilities visible for review. Do not use it as a release-ready dependency update until each issue's named gates pass or the blocker is resolved and revalidated.
